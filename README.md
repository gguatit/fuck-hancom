# Fuck Hancom

Fuck Hancom은 HWP/HWPX 문서를 보고 편집할 수 있는 macOS, Windows, Linux용 데스크탑 앱입니다.

> 이 프로젝트는 [golbin/hop](https://github.com/golbin/hop)에서 포크되었습니다. 원본 프로젝트의 모든 기능을 포함하며, 추가로 메뉴 활성화, 버그 수정, Windows/Linux 메뉴바 지원 등이 포함되어 있습니다.

문서 파싱과 렌더링의 기반은 [rhwp](https://github.com/edwardkim/rhwp)를 사용합니다. Fuck Hancom은 그 위에 데스크톱 껍데기를 씌운 앱입니다. rhwp가 제공하는 기능을 바탕으로 파일 열기, 저장, PDF 내보내기, 인쇄, 파일 연결 같은 OS 통합 기능을 제공합니다.

![Fuck Hancom editor](assets/screenshots/hop-editor.webp)

## 할 수 있는 일

- HWP/HWPX 문서 열기
- HWP 문서 저장, 다른 이름으로 저장
- PDF로 내보내기
- 인쇄 다이얼로그 열기
- 파일 드래그 앤 드롭으로 열기
- `.hwp`, `.hwpx` 파일 연결
- 여러 창에서 문서 열기
